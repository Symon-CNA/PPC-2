# Cálculo Numérico Aplicado - [PPC2]

## Descrição

Este projeto aborda a implementação computacional do **Método de Bairstow** para a determinação de raízes reais e complexas de polinómios de ordem elevada, aplicando-o à análise dinâmica de sistemas físicos e ao mapeamento do seu comportamento numérico.

A modelagem abrange a solução do polinómio característico associado a um sistema massa-mola-amortecedor com múltiplos graus de liberdade, permitindo determinar os autovalores do sistema, as frequências naturais de oscilação e os respetivos fatores de amortecimento. Adicionalmente, explora-se a convergência e estabilidade do método numérico através da geração do **Fractal de Bairstow**, mapeando a velocidade de convergência no plano de estimativas iniciais $(r_0, s_0)$.

## Tecnologias Utilizadas

* **Linguagem:** Python 3
* **Ambiente:** Google Colab / Jupyter Notebook
* **Bibliotecas:** `numpy`, `matplotlib`
